# SigmaSocial

Социальная сеть с поддержкой мобильных платформ (iOS, Android) и веб-версии, построенная на React Native (Expo) и Express.js.

## 📱 О проекте

SigmaSocial — это полнофункциональная социальная сеть, которая позволяет пользователям:
- Создавать и публиковать посты с текстом, изображениями и встроенным контентом
- Комментировать посты и взаимодействовать с контентом
- Ставить лайки постам и комментариям
- Следовать за тегами и находить интересный контент
- Просматривать профили других пользователей
- Прослушивать музыку
- Получать уведомления о важных событиях
- Настраивать профиль и параметры приложения
- Использовать темную тему интерфейса

## 🛠 Технологический стек

### Frontend
- **React Native** (0.76.9) с **Expo** (52.0.46)
- **React Navigation** для навигации
- **Redux Toolkit** для управления состоянием
- **Expo SQLite** для локального хранения данных
- **Socket.io Client** для real-time коммуникации
- **React Native Elements** для UI компонентов

### Backend
- **Node.js** с **Express.js**
- **Prisma ORM** для работы с базой данных
- **MySQL** в качестве базы данных
- **JWT** для аутентификации
- **bcryptjs** для хеширования паролей
- **CORS** для кросс-доменных запросов

### Инфраструктура
- **Nginx** для проксирования и статики
- **Docker** (опционально, через скрипты сборки)

## 🚀 Быстрый старт

### Требования

- Node.js (версия 18 или выше)
- npm или yarn
- MySQL (версия 8.0 или выше)
- Expo CLI (для разработки мобильного приложения)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd SigmaLTD
```

2. **Настройте бэкенд:**
```bash
cd backend
npm install
# или
yarn install
```

3. **Настройте переменные окружения:**
```bash
cp env.example .env
```

Отредактируйте `.env` файл:
```env
DATABASE_URL=mysql://user:password@localhost:3306/database_name
JWT_SECRET=your-secret-key-here
PORT=3000
```

4. **Настройте базу данных:**
```bash
npx prisma generate
npx prisma migrate dev
# или
yarn prisma generate
yarn prisma migrate dev
```

5. **Настройте фронтенд:**
```bash
cd ../frontend
npm install
# или
yarn install
```

### Запуск

#### Разработка

**Бэкенд:**
```bash
cd backend
npm start
# или
yarn start
```

**Фронтенд:**
```bash
cd frontend
npm start
# или
yarn start
```

Затем выберите платформу:
- `a` для Android
- `i` для iOS
- `w` для веб

#### Продакшн

Используйте скрипт `start` в корне проекта:
```bash
./start
```

Или используйте скрипты сборки:
```bash
./build-back.sh
./build-front.sh
```

## 🔐 Аутентификация

Приложение использует JWT токены для аутентификации. После успешного входа пользователь получает токен, который должен быть включен в заголовок `Authorization` всех защищенных запросов:

```
Authorization: Bearer <token>
```

## 🗄 База данных

Проект использует Prisma ORM для работы с MySQL. Основные модели:

- **Users** — пользователи системы
- **Nsu** — данные NSU (если применимо)
- **Post** — посты пользователей
- **Comment** — комментарии к постам
- **Tag** — теги для категоризации контента
- **Notification** — уведомления пользователей
- **PushSubscription** — подписки на push-уведомления

Для просмотра полной схемы базы данных см. `backend/prisma/schema.prisma`.

## 🎨 Темы

Приложение поддерживает темную тему, которая настраивается через `ThemeContext` и `ThemeProvider`.

```bash
cd frontend
eas build --platform ios
```

## 🔧 Конфигурация Nginx

Пример конфигурации Nginx находится в `nginx.conf`. Настройте его в соответствии с вашими требованиями для проксирования запросов к бэкенду и раздачи статических файлов фронтенда.

## 📝 API

API документация находится в процессе разработки. Основные эндпоинты:

- `POST /api/auth/login` — вход в систему
- `POST /api/auth/register` — регистрация
- `GET /api/posts` — получение постов
- `POST /api/posts` — создание поста
- `GET /api/posts/:id` — получение конкретного поста
- `POST /api/posts/:id/like` — лайк поста
- `POST /api/comments` — создание комментария
- `GET /api/users/:id` — получение профиля пользователя
